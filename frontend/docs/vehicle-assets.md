# Current local assets

Only BMW M2 Coupé G87 2023 is shipped: `public/models/bmw-m2.glb`, by Outlaw Games™, CC BY-NC 4.0. See [attribution](../public/models/ATTRIBUTION.md).

Civic RS e:HEV and Prelude were removed at the user's request. VF 3, VF 9, CR-V and Kona were also removed because local files are not available in this project. No assets were extracted from embedded viewers.

Add properly licensed GLBs to `public/models` and register them in `src/lib/vehicles.ts`. Validate orientation, paint materials and hotspot positions per asset; these are currently tuned for the BMW. Local thumbnails must be under `/models/` too. Source URLs are attribution links only and are not fetched by the app.

The `archive` folder records previous research and remote-viewer checks, not the current catalog.
