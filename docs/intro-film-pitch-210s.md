- Working directory `brag-output/pitch-210s-2026-10-16/` (gitignored): composition, voice clips, plan, brief, share copy, snapshots.

## How it is built

`composition/index.html` mounts three sub-compositions generated by `composition/build.py` from `src/`. The narration lives in `voice/script.json`; `voice/synth.py` calls `BlazeTTS` from `backend/voice.py` (token only from `backend/.env`, never printed), `voice/assemble.py` places the clips on the 210 s timeline and writes timing and captions. Scene timing follows the generated audio. Re-render with Node 22+: `python3 composition/build.py && npx hyperframes@0.8.146 check && npx hyperframes@0.8.146 render -q looks --crf 20 -o ../brag.mp4`.

The chapter list in `components/film/timeline.ts` (8 chapters, `TOTAL = 210`) follows the MP4. Change both together.

## What is on screen is grounded

Thresholds (105 °C / 120 °C, 1.5 s / 2.5 s eye closure), 15 records per batch, `DriverEvent` with `extra="forbid"`, `COOLANT_CRITICAL_C`, the Guardian policy in Python and TypeScript tested against `guardian_cases.json`, the plan matrix in `plan.py`, `_claim` keys, Blaze `/download` 425, navigation 0.2 s → 10 s on software WebGL. Car data is labelled "illustrative demo scenario" on every frame. No claim of vehicle control, emergency calls or safety certification.

## Validation

`npx hyperframes check`: 0 errors (lint, runtime, layout, motion, contrast). ffprobe: 210.000 s video and audio. The last second of each part is silent. `scripts/verify-film.mjs` passes at 320, 390 and 1440 px; at 768 px it fails only because the site header's language switch overflows (`site-header.tsx` has uncommitted changes that are not part of this work).
